# 发布速记

- 版本只改 `package.json.version`，并在本文件补一节同名版本记录。
- 执行 `npm run release:prepare`：统一生成演示页、调试页、两种壁纸包，运行测试与一致性检查，输出 `dist/release.json` 和 `dist/release-notes.md`。
- 提交并推送源码及生成产物，GitHub Pages 自动部署；按清单上传两个 ZIP 到对应版本 Release，并设为 Latest。
- 演示页的下载入口固定指向 Latest；资源缓存标识由内容自动生成，不手改页面版本号或生成文件。已经下载的离线壁纸需重新下载导入。

## v3.3.0 — 2026-10-17
