# TIMEFORM

[Open the gallery / 打开展示页](https://xxxddd.github.io/clockclock24/)

由多只模拟时钟组成的动态时钟，提供 30 款预设。可作为 Lively Wallpaper 或 Wallpaper Engine 桌面壁纸使用。

- **Lively Wallpaper**：[下载壁纸包](https://github.com/XXXDDD/clockclock24/releases/latest/download/TIMEFORM-Lively.zip)。将 ZIP 拖入 Lively，导入后在壁纸的「自定义」中切换款式和调整设置。
- **Wallpaper Engine（试用版）**：[下载壁纸包](https://github.com/XXXDDD/clockclock24/releases/latest/download/TIMEFORM-WallpaperEngine.zip)。解压到 Wallpaper Engine 安装目录下的 `projects/myprojects/TIMEFORM` 文件夹，在壁纸编辑器中打开该项目并应用。

The wallpaper packages include English and Simplified Chinese settings and instructions. Both platforms follow their interface language; the offline Lively settings page also offers a language selector. Download filenames are English in every language.

壁纸包内含中英文设置与说明，原生设置面板跟随平台语言；离线配置页支持手动切换。所有语言使用同一个下载包，文件名统一为英文。
