# AMT61c Zephyr 型号设计

**投影校准（2026-10-17）**：官方圆板直径 146 cm。重复阵列与独立外圆轮廓恢复度量平面后，轴距约为板径的 8.967%，表盘直径约为轴距的 93.059%。模型回投影检查全部表盘与外围留白，依据和误差见[投影对齐与尺寸校准](../geometry-reference.md)。

**当前网页范围（2026-10-17）**：以 [product.md](../../../product.md) 为准。AMT61c 的 Zephyr 风势与 Tidal 环弧动作可在同型号预设之间共享，切换动作不改变配色或几何；Zephyr 默认仍使用本文已校准的 53.1 秒实现。时长、颜色与几何可调，具体规则见[同型号参考动作](../../web/shared-actions.md)。下文其他通用模式属于底层兼容及历史验证，不作为网页动作选项。

AMT61c Zephyr 的动画按表盘位置组织节奏。数字与装饰决定读时姿态，但不能各自只配一条动画：开头的装饰表盘同时存在左右延迟和距中心行的延迟；结尾的装饰表盘主要保留左右相位差，同列上下的可见动作则接近一致。每个表盘需要自己的运动时间和针位，经过验证的位置组可以共用参数。

更新日期：2026 年 10 月 16 日。本文作为本型号首尾动画实现和调试的依据。现实现保留已认可的风状编排，首尾改用逐针轨迹、位置时序与独立到位时间；整体顺时针与共同归位截止时间已不再作为实现约束。

## 参考与坐标

参考为[官方 Zephyr 产品页](https://www.humanssince1982.com/en-int/products/a-million-times-61c-zephyr)的[演示视频](https://www.humanssince1982.com/cdn/shop/videos/c/vp/d2d7cd358c664452aa9d81a0931eb5ec/d2d7cd358c664452aa9d81a0931eb5ec.HD-1080p-7.2Mbps-46730750.mp4?v=0)。视频长 53.12 秒，25 fps，共 1328 帧，展示 09:34 到 09:35 的一次转换。其他时间的路径和圈数仍需在后续调试中定义，不能从这一段推定完整官方程序。

表盘使用与 `model.js` 一致的零起始坐标。行 `r` 从上到下为 0–8，列 `c` 从左到右为 0–8。上下对应位置为 `(r,c)` 与 `(8-r,c)`，中心行为 `r=4`。

```text
             c3 c4 c5                 r0
       c1 c2 c3 c4 c5 c6 c7           r1
       c1 c2 c3 c4 c5 c6 c7           r2
    c0 c1 c2 c3 c4 c5 c6 c7 c8       r3
    c0 c1 c2 c3 c4 c5 c6 c7 c8       r4
    c0 c1 c2 c3 c4 c5 c6 c7 c8       r5
       c1 c2 c3 c4 c5 c6 c7           r6
       c1 c2 c3 c4 c5 c6 c7           r7
             c3 c4 c5                 r8
```

中央三行中，`c0–c3` 和 `c5–c8` 是四个数字的 24 个候选表盘；其余 37 个位置始终用于装饰。数字候选位置在某些时间也会呈现装饰姿态，因此不能把“数字表盘”理解为永久参与笔画的固定类型。

针的方向均按正面画面说明：右为三点方向，下为六点方向，左下约为七点半方向。若使用角度，朝右为 0°，顺时针为正，朝左下约为 135°。

## 整体流程

| 原片时间 | 动作 | 阶段边界 |
| --- | --- | --- |
| 0–约 1 秒 | 09:34 稳定读时，装饰双针重合朝左下。 | 起动前的读时姿态。 |
| 约 1–10 秒 | 原有数字依次拆散，装饰针组也按位置依次转向，最终全部朝右重合。 | 各表盘陆续完成，先到位的等待。 |
| 约 10–15 秒 | 全体朝右重合并静止。 | 有明显的共同静止区间。 |
| 约 15–40 秒 | 两针反向持续绕转，开合起伏从左向右传播，重复数轮。 | 保留当前已认可的风状编排。 |
| 约 40–50 秒 | 从各自的波浪姿态直接进入 09:35，装饰针组逐渐收拢朝左下。 | 风势与成型有衔接，各表盘的进入和停止不必同刻。 |
| 约 50–53 秒 | 09:35 稳定读时。 | 全阵列完成后保持。 |

这些区间描述整幅画面，不能直接作为所有表盘共用的起止时刻。尤其在风势转入成型时，同一帧中可以同时存在仍像波浪的表盘和已经接近读时的表盘。

## 开头整理的位置节奏

### 同为装饰的表盘也分层起动

中央 `c4` 一整列都是装饰位置，初态和目标态相同，适合单独检查位置影响。它们并不一起转动：中心 `R4C4` 先动，随后是 `R3C4 / R5C4`，再向最上、最下两端展开。同一时刻，靠近中心的已经接近朝右，外侧还可能保持朝左下。

| 中央列位置 | 明显开始偏离初态的时间 | 约 5 秒时的可见姿态 |
| --- | --- | --- |
| R4C4 | 约 2.4 秒 | 已经接近朝右，略向右下。 |
| R3C4 与 R5C4 | 约 3.2–3.4 秒 | 朝右下。 |
| R2C4 与 R6C4 | 约 3.8–4.0 秒 | 接近朝下。 |
| R1C4 与 R7C4 | 约 4.4–4.8 秒 | 仍接近左下，正在转动。 |
| R0C4 与 R8C4 | 约 5.2 秒 | 基本仍保持初始左下方向。 |

这里的起动时间是可见偏转的近似读数，不是电机真正开始运动的精确帧。

![开头中央装饰列逐位置对比](C:/Users/win/Desktop/网页时钟/artifacts/zephyr-position-start-vertical.png)

### 左右位置同时影响延迟

固定在 `r1`，从 `c1` 到 `c7` 的装饰表盘也依次起动。左端 `R1C1` 约 3.2 秒出现明显转动，中间 `R1C4` 约 4.8 秒，右端 `R1C7` 约 6 秒。它们的姿态变化相似，主要是发生时间不同。

因此，开头更接近“由左侧中心附近向右、向上下展开”的时序，而不是只按列延迟，也不是数字完成后装饰统一起动。

![开头同一装饰行的左右对比](C:/Users/win/Desktop/网页时钟/artifacts/zephyr-position-start-horizontal.png)

### 上下对应位置可共享节奏

`R0C4 / R8C4`、`R1C1 / R7C1`、`R2C1 / R6C1` 等装饰位置的可见针组动作近似同相，可以作为共享节奏参数的候选组。这里是上下位置对应、针的方向近似相同，不是把上方针位做上下翻转后复制给下方。

上下对应只作为已经核对的装饰组规则。数字区域上下对应位置的起止笔画可能不同，不能直接复制完整针位轨迹。

### 转向与开合由起始针位决定

装饰双针开始时已经重合，它们可以保持重合，沿“左下 → 下 → 右下 → 右”的路径转向，按画面观看是逆时针。数字区则会出现只动一根针、另一根基本保持，以及两根共同调整的情况。例如 0 左上角的一根原本朝右，另一根从朝下逐渐收向右。

部分数字位置原本就朝右重合，如这段片中的 `R3C5`，无需为了参加统一阶段再额外绕动。动作时间由位置组织，实际行程还取决于当前针位。

## 风状编排的保留范围

当前网页版的风状编排已经得到认可，首尾调试以它为基准，不同时重写起风、周期、快慢曲线或传播观感。

原片中，一根针顺时针、另一根逆时针持续绕转；重合时继续穿过，随后再次张开。相邻列的进度差形成横向传播的风势。完整一轮可见形态包括朝右重合、开口朝右的双针、上下对向、开口朝左的双针、朝左重合，再回到朝右重合。

实现需要保留展开的旋转角度，不能用始终小于 180° 的几何夹角代替整个运动相位。双针重合后的画面本身不能辨认实体针的编号，逐帧对比以可见针组轮廓为准。

## 结尾成型的位置节奏

### 从风势直接进入读时

各表盘从当前波浪相位继续运动，不先全体回到朝右重合，也不先做一次全阵列刹停。数字区逐渐形成 09:35，装饰针组则继续转向和开合，最后朝左下重合。

轨迹必须延续旋转方向与已有圈数；经过交叉或重合后仍可能继续运动，不能一碰到目标的等价角度就提前认定完成。是否需要额外一圈要按单针轨迹核对，不能给所有表盘统一增加圈数。

### 装饰表盘的纵向差异明显缩小

结尾的中央装饰列 `c4` 与开头不同。约 40 秒时整列都是接近的开合形状；约 42 秒接近上下对向；约 44–47 秒共同经历转向和收拢；约 49–50 秒朝左下重合。该列不同高度的可见动作近似一致。

开头显著的 `abs(r-4)` 延迟，不能直接原样套到结尾，更不能把开头倒放当作成型。

![结尾中央装饰列逐位置对比](C:/Users/win/Desktop/网页时钟/artifacts/zephyr-position-return-vertical.png)

### 左右仍有相位差并逐渐收束

固定在 `r1`，约 40–42 秒左侧和右侧的开合姿态明显不同；随后各列逐渐靠拢，约 49–50 秒都成为朝左下重合。结尾既继承风势的左右相位差，又让这些差异在成型过程中消失。

`R1C1 / R7C1`、`R2C1 / R6C1`、`R1C7 / R7C7` 的上下对应装饰组在结尾仍呈现近似相同的可见动作。纵向共享节奏的证据较强，左右共用同一瞬时姿态的证据不成立。

![结尾上下对应装饰组](C:/Users/win/Desktop/网页时钟/artifacts/zephyr-position-mirror-return.png)

### 数字针的到位顺序另行处理

相同位置节奏下，数字需要的最终笔画不同，单针行程和停止时刻也会不同。原片中的 0 左上角能看到一根先保持朝下，另一根仍继续转向朝右；0 中部的竖线也早于部分装饰表盘稳定。

因此，设计以“整个读时画面在一个完成区间内稳定”为目标，不要求 122 根针严格同一帧停止。装饰组可以在相近时间收束，数字针仍需允许先到位后保持。

## 后续实现规则

### 用位置组织节奏 用针位决定路径

每个表盘保留 `row`、`col`、距中心行的距离、上下对应组、当前双针姿态和目标双针姿态。数字或装饰用途只负责目标姿态与显隐，不单独决定整段动画。

开头可先采用下式作为待调试的位置延迟模型：

```text
alignDelay(r,c) = base + horizontalDelay * c + verticalDelay * abs(r - 4)
```

对这段片中装饰表盘的明显起动时刻进行近似比较，左右每列约相差 0.4 秒，离中心行每远一行约相差 0.65–0.7 秒。这是位置延迟的重建起点，不是官方参数；开始缓动和可见偏转阈值会影响基准时间。先共用已经核对的装饰转向曲线，再按位置平移时间，必要时保留单表盘修正。

成型另设时序：继承当前风势相位，装饰组优先按列组织，不能复用开头的纵向延迟。上下对应装饰组可复用参数；数字针根据目标笔画分别规划行程与停止。

### 每根针保留自己的到位信息

每组至少记录进入本阶段的时刻、两根针的当前角度与速度、展开角度、各自目标角度、各自停止时刻和整组保持区间。所有阶段共用播放时间轴，但不共用单一运动进度或逐针停止时刻。

“整体朝向与开合”的分解可以作为计算工具，不作为强制的顺时针运动规则。只有在它能准确表达已经观察到的单针路径时才采用；不要为了维持某个分解方向而新增绕圈或改变可见节奏。

### 首尾调试顺序

1. 固定 09:34 → 09:35、约 53 秒，先核对原片对应的开头和结尾。
2. 开头先调中央装饰列，再调装饰横排和上下对应组，最后调数字区的单针收拢。
3. 结尾先保持风势不变，核对同列装饰的共同轨迹、左右相位收束，再调数字针的路径和停止先后。
4. 首尾动作成立后，再检查其他时间、已有 12:36 场景、缩短时长、暂停、单步与中途更新时间。

## 网页实现记录

开头以 53.12 秒为基准，位置起动时间采用 `0.2 + 0.4 * c + 0.7 * abs(r - 4)` 秒，局部转向用时 4.6 秒；整体时长变化时同比缩放。每根针独立取朝右的最近等价角度，已经朝右的针保持，装饰重合针沿左下、下、右下、右的方向转动。所有位置提前完成后共同停留。

风势的速度曲线、周期、列间延迟及轻微纵向相位差保持原实现。为保留这段已认可的编排，网页仍以全长的 28% 起风、80% 进入成型，94% 前完成；这些比例是网页重建参数，不能替代上文原片的近似时间区间。

成型从风势的当前展开角度和速度直接规划。每根针沿原旋转方向到达下一等价目标角度；接近目标时缩短制动时间，不统一增加圈数。装饰组按列安排相近的到位区间，同列上下不再叠加开头的纵向延迟；数字针按各自目标和剩余行程安排停止。轨迹使用保持入口速度、出口速度为零的插值，提前到位的针保持。播放中换时沿用当前角度与速度重新规划，风势期间只更新最终目标。

以上路径是基于现有观察资料的网页版重建；其他时间的正确读时、缩短时长及中途换时由回归验证覆盖，不代表已获得官方完整电机程序。
