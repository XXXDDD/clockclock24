## 布局与外观

九组双针直接安装在圆板上，没有独立小表盘、刻度或外加圆形轴帽。正面坐标从右为 0°，顺时针为正。中心为 `(0,0)`，外围按 N、NE、E、SE、S、SW、W、NW 排列：

```text
                N (0,-2)
       NW (-1,-1)       NE (1,-1)
W (-2,0)        center        E (2,0)
       SW (-1,1)        SE (1,1)
                S (0,2)
```

白色圆板用轻微明暗表现体积；深灰针臂为平直、方端的长条，阴影轻而清楚。外围两臂默认等长，中央时针略短。新方案的针宽默认 6.2 设计单位、中央时针比例 82%；网页版固定针臂长度、粗细、颜色和轴心间距，旧方案仅恢复使用设置。

100% 针长使用基准半径的 86.9%，相邻轴之间约保留 13% 的针尖间隙。即使轴心额外间距为 0，也不能拼成无缝菱形或让针尖重叠。

外围静态针位指向两侧相邻轴。中央第一针为分针，第二针为时针；时针随分钟连续推进，12／24 小时制只影响调试读数。参考片中的中央轮廓作为造型依据，网页按真实时间计算两针方向。

## 参考片段的运动观察

| 片段时间 | 可见行为 | 实现含义 |
| --- | --- | --- |
| 0–约 2.5 秒 | 九组双针接近反向共线，平行斜线顺时针扫向接近水平。 | 共同姿态近似 `-45° / 135°`，随后有一段共同扫动；不能按目标时间任意改变片头姿态。 |
| 约 2.5–8 秒 | 各组持续顺时针，部分针逐渐靠近，其他针继续越过；外围逐步出现拐角。 | 同步线条逐渐散开，各位置和单针有不同剩余行程、速度曲线。 |
| 约 8–10.8 秒 | 菱形接缝逐渐对齐，中央完成读时，整体减速。 | 保留展开角度，平滑接入最终针位，避免最后一帧跳角。 |

两针相对方向在共同阶段约差 180°，不是重合为一根单向针。整组几何轮廓相同也不代表同编号的针在所有轴上指向同一侧。E、SE、S、SW 四组使用与另一侧相反的针臂分配，才能衔接片段中的各自路径。

## 网页重建流程

### 顺时针追齐

从当前各针姿态出发，按位置追齐到固定斜直线 `-45° / 135°`。这一段占总时长的 18%，为网页补足的起步。每根针保留自己的展开角度、当前速度和行程。只在追齐和衔接速度确实需要时增加一圈，避免倒转；到共同姿态时速度不降为零。

### 共同扫动

斜直线以共同速度顺时针扫过约 45°，到接近水平。其用时为追齐后剩余时长的 22%，即总时间轴的 18%–36.04%。这段有持续转动，不额外加入统一静止、呼吸、反向开合或 Zephyr 波浪。

### 菱形成型

从共同扫动的当前角度和速度，按各根针的剩余行程逐渐散开并成型。参考目标附近的外围分配如下；第一／第二臂的编号与 `model.js` 的最终针位一致。

| 位置 | 第一臂在共同斜线时 | 第二臂在共同斜线时 | 两针到最终外围造型的行程 |
| --- | --- | --- | --- |
| N | -45° | 135° | 180° / 270° |
| NE | -45° | 135° | 270° / 270° |
| E | 135° | -45° | 90° / 180° |
| SE | 135° | -45° | 180° / 180° |
| S | 135° | -45° | 180° / 270° |
| SW | 135° | -45° | 270° / 270° |
| W | -45° | 135° | 90° / 180° |
| NW | -45° | 135° | 180° / 180° |

中央分针在参考附近保留超过一圈的展开行程，时针可以只有较短行程。其他读时沿用相同的共同姿态，按各自实际目标和旋转方向规划；不能为了让全部针都长途旋转而统一套用多圈。网页版移除额外的“多圈顺时针成型”模式。

各针的速度保持非负，成型入口延续扫动速度，出口为零。同为 270° 行程，N／S 端与 NE／SW 两组的中途姿态并不相同：N／S 更接近持续扫动，NE／SW 有较强的中段加速。因此速度曲线按位置和单针安排，不只按行程复制。普通编排中，外围半圈及以上的 N／E／SE／S／W／NW 行程采用短暂调速、持续扫动和末段制动；NE／SW、短弧及中央针使用保持入口速度的连续起伏曲线。网页采用共同完成时刻，避免长时间提前到位后等待。原片中极小的可见位移不用于认定精确停针帧。当前速度曲线是满足这些边界的解析重建，不声称完整复现官方电机曲线。

## 换时与播放控制

- 共同姿态和共同扫动不依赖目标时间。成型之前修改目标，只更新未来的中央读时；已有起步、共同扫动和外围路径继续。
- 成型期间改时间，从当前角度和速度重新规划变化的中央针，外围路径继续。剩余时间不足 350 ms 时延长到至少 350 ms，仍保留当前运动状态，避免瞬间跳转。
- 在动画中重播，从当前角度及速度继续顺时针追齐；配色、几何与速度调整不能重置进度。
- 暂停、继续和单步使用公共播放时间轴；采样本身不能累加圈数，重复采样同一时刻必须一致。
- 网页不再提供“安静读时”或“立即换时”模式；系统减少动态效果偏好仍使用短途过渡。

## 验收

固定 10:09 → 10:10，先核对追齐时的平行斜直线和共同扫动，再检查散开、中央长短针行程与最终接缝。逐帧应保持顺时针，两个阶段边界不丢失速度；最后正确显示中央模拟时间和有留白的外围菱形。
