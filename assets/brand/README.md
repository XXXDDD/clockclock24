# 时阵

黑白标志由六枚表盘和双针组成，针位直接取自 ClockClock 24 的数字「7」字形；左下两枚表盘保留斜线姿态，表达多个模拟表盘组成数字时间的产品特点。

`src/brand/identity.json` 定义品牌与几何，`scripts/build-brand.cjs` 生成 SVG、安卓普通图标和自适应图标。`shizhen.png` 是同一矢量图形的预览，可通过 `python scripts/render-brand.py` 重建。安卓 13 及以上同时提供单色主题图标。

运行时命名空间、配置标识、安卓包名和既有桌面下载地址保留兼容。安卓公开名称为「时阵」，安装包为 `Shizhen-Android.apk`。
